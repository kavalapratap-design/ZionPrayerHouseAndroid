# Zion Prayer House Android App — Starter v0.1

A bilingual (Telugu + English) Android starter project built with Kotlin and Jetpack Compose.

## Included in this first milestone
- Home screen with Zion Prayer House branding
- Telugu / English language toggle
- Bottom navigation: Home, Bible, Sermons, Events, Prayer, More
- Placeholder screens for content that will be connected in later phases

## Build
1. Install Android Studio (latest stable) on a computer.
2. Open this project folder in Android Studio.
3. Allow Gradle sync and install the required Android SDK (API 35).
4. Select a device/emulator and press Run.

Application ID: `org.zionprayerhouse.app`

## Important
This is an initial UI starter, not a finished production app or installable APK.
Bible text, audio/video hosting, prayer-request storage, notifications, and secure admin login still need to be implemented and tested.
No Firebase keys, payment credentials, or private church/member data are included.
